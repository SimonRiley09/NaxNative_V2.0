# Nax
Nax is an app created to let you take back control of what you watch.
*You need to modify .env and config.js
To run, first ```cd backend``` then ```docker compose up -d``` To run the backend.
To run the front end, go to the root directory, then ```cd Nax-Native-V2.0``` and start the app for expo go: ```npx expo start --tunnel```.
